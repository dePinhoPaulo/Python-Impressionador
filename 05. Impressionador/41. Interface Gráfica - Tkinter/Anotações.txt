AULA_06: Grid - Organizando as Janelas do Tkinter

    Editar posicionamento dos elementos na janela:
        menssagem2 = tk.Label(text="Selecione a moeda desajada:")
        menssagem2.grid(row=1, column=0)

        moeda = tk.Entry()
        moeda.grid(row=1, column=1)

        Grid: Funciona como um excel, escolhemos a linha e coluna de cada elemento.

    Meclar celulas:
        menssagem.grid(row=0, column=0, columnspan=2, sticky='ew')
        columnspan: mescla as celulas;
        sticky: Preenche completa mente as celulas mecladas, parametros(leste, oeste, norte, sul. iniciais em ingles)

    Redimensionamento automacio das linha e coluna na janela:
        janela.rowconfigure([0], weight=1)
        janela.columnconfigure([0, 1], weight=1)

AULA_10: Caixa de Textos Grandes

    Funcionalidade para buscar mais de uma cotação de moeda:
    def buscar_cotacoes():
        texto = caixa_texto.get("1.0", tk.END)
        lista_moedas = texto.split("\n")
        menssagem_cotacao = []
        for item in lista_moedas:
            cotacao = cotacoes.get(item)
            if cotacao:
                menssagem_cotacao.append(f'{item}: {cotacao}')
        menssagem4 = tk.Label(text='\n'.join(menssagem_cotacao))
        menssagem4.grid(row=6, column=1)
