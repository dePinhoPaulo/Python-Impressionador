AULA_03: Classes e Objetos

    Tudo no python é um objeto;
    Objetos, na verdade, são Classes em python;
    Cada Classe tem Métodos e Atributos;

    Classes:
        Classe = Objeto
            Metdodos = O que aquele Objeto consegue fazer?
            Atributos = Quais são as informações/propriedades do Objeto
        
        Classe = Pessoa
            Metdodos = Andar, Pular, Correr...
            Atributos = Peso, Altura, QI, Tipo Sanguineo...
        
        Classe = TV
            Metdodos = Ligar TV, Mudar volume, canal...
            Atributos = Cor, Canal, Volume, Tamanho da Tela, É SmartTV..
        
    Classes: Exemplos que já usamos
        Classe: String
            Métodos: Replace, Find, capitilize, Format

        Classe: pandas.DataFrame
            Métodos: append, copy, dropna, groupby, filter
            Atributos: iloc, shape, columns, values, loc...

    Cada Objeto é um Tipo. Dizemos: “É um objeto do Tipo String, é um objeto do tipo int, é um Objeto do Tipo DataFrame...”;
    Vamos ver na próxima aula como isso é criado dentro do Python.


AULA_04: O que é uma Classe no nosso código

    Classe é um modelo ou uma planta usada para criar objetos. 
    Ela junta dados (chamados de atributos) e ações (chamadas de métodos) em um único lugar. 
    
    Tudo em Python é baseado nisso: 
        um texto é um objeto de uma classe de texto, e um número é um objeto de uma classe de número.
    
    Componentes de uma Classe:
        Atributos: As variáveis que guardam as características de um objeto;
        Métodos: As funções que definem o que o objeto pode fazer;
        __init__: O método especial usado para iniciar o objeto com seus valores básicos;
        self: A palavra que representa o objeto específico que você está usando no momento.


AULA_05: Conceitos Importantes sobre Programação Orientada a Objetos

    Programação Orientada a Objeto X Programação Estruturada
        Orientada a Objeto (POO):
            Classes:
                Classe TV:
                    Método mudar_canal:
                    Método mudar_voluma:
                    Método ligar_desligar:
            
            Programa:
                minha_TV = tv()
                minha_TV.ligar()
                minha_TV.mudar_canal('Netflix')
                minha_TV.mudar_volume(55)
            
        Programação Estruturada:
            Programa:
                var = 1
                lista = [1,2,3,4,5]

                for item in lista:
                    if item == variavel:
                        print(f'(var) encontrado!')
                print('fim do programa!')
    
    Qual a vantagem da Orientação a Objeto?
        Aproveitar o código sem precisar refazer/copiar tudo
        Encapsulamento -> Proteção a mudanças indesejadas (ex: TV – você não pode desligar a tv no botão de mudar o volume)
        Herança -> Instâncias do Objeto tem as mesmas características, apesar de ter valores diferentes
        Polimorfismo -> Um mesmo método pode ter várias “formas” em diferentes classes (ou subclasses) – ex: Animais -> Gatos x Cachorros


AULA_06: Criando nossa 1ª Classe

    Dentro da classe, você vai criar a "função" (método) __init__
    Esse método é quem define o que acontece quando você cria uma instância da Classe

    Atributos e valores inicis da nossa classe:
        class TV:
        def __init__(self):
            self.cor = 'preta'
            self.ligada = 'delidada'
            self.tamanho = 55
            self.volume = 12
            self.canal = 'Netflix'


AULA_07: O que é o self das Classes

    self é uma convenção para representar a instância atual da classe, ou seja, o objeto específico que você criou e está manipulando no momento.
